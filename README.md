# 📎 Clipper

Clipper es una aplicación de escritorio para Windows diseñada para organizar archivos automáticamente mediante reglas inteligentes y futuras capacidades de IA.

## Objetivo

Ayudar a mantener ordenadas carpetas como:

- Descargas
- Documentos
- Imágenes
- Videos

mediante clasificación automática y herramientas de gestión de archivos.

## Estado actual

### V0.1
- Lectura de archivos en Descargas
- Detección de extensiones
- Creación automática de carpetas
- Organización básica por tipo de archivo

## Tecnologías

- Python
- pathlib
- shutil
